>

---

## 🔥 הפילטר החדש: "סיר הלחץ"

6 קריטריונים מחמירים לזיהוי פריצות:

| קריטריון | כלל |
|----------|-----|
| RSI | 50-75 |
| נפח יחסי | ≥1.5x |
| שינוי יומי | +2% עד +10% |
| רוחב Bollinger | <0.15 |
| מרחק משיא 52 שבועות | ≥95% |
| יישור EMAs | מחיר > EMA20 > EMA50 |

**תוצאה:** מ-1000+ מניות → רק ~10-15 מועמדים

## 💰 מסחר נייר

| פרמטר | ערך |

| הון התחלתי | $100,000 |
| גודל פוזיציה | $2,000 (קבוע) |

### כללי יציאה:

| כלל | תנאי | פעולה |
|-----|------|-------|
| **Stop Loss** | -3% | מכירת 100% |
| **Take Profit 1** | +5% | מכירת 50%, SL → breakeven |
| **Take Profit 2** | +10% | מכירת הכל |
| **Time Stop** | 48h ללא תזוזה | מכירת הכל |

## 🧠 למידה עצמית

- מעקב ב-6 נקודות זמן: 10, 20, 30, 40, 50, 60 יום
- WIN = +10% או יותר
- LOSS = -5% או פחות
- התאמת משקלים אוטומטית
